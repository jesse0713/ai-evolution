# AI 自主训练 · 进化记录

一个 AI 自己学会叠方块。每晚训练、每晚直播，这个仓库保存它**每一代的原始记录**。

📊 **在线查看**：<https://YOUR_USER.github.io/YOUR_REPO/> （GitHub Pages，仓库设置里开启）

## 这是什么

每晚直播时，屏幕上那个 AI 在自己训练。它的每一代都做三件事：

1. 生成 30 组候选权重
2. 每组跑 30 局（固定种子，代际之间可比）
3. 留下最好的那组继续进化

这个仓库保存的就是这些过程的**原始数据**——每一代的权重、成绩、步数。

## 怎么看

打开 `index.html`（或上面的在线链接），能看到：

- **跨代曲线**：每一代的最好成绩。曲线上的竖虚线是**规则变更点**——
  第 36 天起关掉了方块预告（等于考试时不能偷看下一题），成绩会下跌。
  **那是换了考试难度，不是 AI 退步。**
- **每天的权重**：9 个评价指标的权重变化。绿色是奖励方向的权重，红色是惩罚方向。
  `✓` 表示这一维的最优方向与已发表的专家手调基线一致。
- **原始文件**：本页每一个数字的来源。下载后可以自己跑一遍复现。

## ⚠️ 关于这些数字的口径

- 游戏场地、计分与重力曲线均为本项目**自研规则**，与任何商业版本**不可比**。
- 因此这些分数**只在实验内部有意义**：可以横向比较（今天 vs 昨天），
  但**不代表任何外部纪录**，也不与任何其他作品的成绩直接比较。
- 评估使用固定种子集，代际之间可比、可复现。

## 验证方式

```bash
# 每个权重文件都带固定种子与评估局数
cat data/weights/gen_00009_day3.json
# {"generation": 9, "fitness": 900.0, "seed_base": 20260101, ...}
```

用同样的种子跑同一份权重，应当得到同样的成绩。
